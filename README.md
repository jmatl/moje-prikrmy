# Moje příkrmy

Standardní Android aplikace pro rodinný deníček prvních příkrmů.

- lokální data fungují i bez internetu
- přidání, úprava, smazání, vyhledávání a filtry
- stav Chci zkusit / Ochutnáno
- datum, hodnocení, reakce, poznámky
- rodinný klíč a sdílení
- online synchronizace přes API, pokud je dostupné

GitHub Actions workflow `.github/workflows/android.yml` sestavuje a ověřuje standardní `app-debug.apk` přes Android SDK/Gradle.
